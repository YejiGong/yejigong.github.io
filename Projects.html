소규모 DBMS 구현

done

2023.05
중앙대학교 - 데이타베이스시스템

Java

MySQL

  
Bitmap Index를 지원하는 DBMS를 소규모로 구현하였습니다.
File I/O를 기반으로 직접 DBMS의 내부 시스템을 소규모로 구현해 보는 프로젝트로, 테이블 생성, 레코드 삽입, bitmap index 생성, multiple-key 질의처리, 집계함수 처리를 구현했습니다.

View단을 내부 로직과 분리해 준 후, 내부는 실제 DBMS 내부 구조를 참고하여 Query Processor, Storage Manager으로 나누어 구현했습니다.
데이터 파일을 버퍼를 통해 블록 단위로 읽어오고, 레코드 단위로 나눈 후 레코드의 저장만 실제 DBMS 내부에 합니다. 이후 인덱스 생성을 위한 컬럼이 지정되면 DBMS에서 레코드값을 버퍼로 불러와 bitmap index 결과 값을 파일로 생성하도록 했습니다.
사용자가 질의문을 입력하면, 생성된 bitmap index파일을 활용해 결과 값 레코드 id값을 찾아내도록 했습니다. 그리고 해당 레코드의 데이터값을 DBMS에서 받아서 결과물 파일을 생성 및 출력하도록 했습니다.

해당 프로젝트를 통해 직접 DBMS 내부를 소규모로 구현해 보면서, 시스템이 어떻게 동작하는지에 대한 이해도를 높일 수 있었습니다.
